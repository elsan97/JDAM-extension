##  Как установить (если ты не прогер)

1. Скачай `.zip` архив из раздела **[Releases](https://github.com/elsan97/JDAM-extension/releases)** (кнопка выше).
2. Распакуй его в любую папку на компе (и не удаляй её потом, а то расширение отвалится).
3. Открой в браузере `chrome://extensions/` (или `edge://extensions/`).
4. Включи тумблер **«Режим разработчика»** (Developer mode).
5. Нажми **«Загрузить распакованное расширение»** и выбери эту папку.
6. Иди на любой сайт, жми на иконку 💣 и выбирай цель.

##  Как собрать самому (для тех, кто умеет читать код)

Если ты хочешь залить это себе локально:
```bash
git clone https://github.com/elsan97/JDAM-extension.git
```
Дальше кидаешь папку в `chrome://extensions/` и кайфуешь!

> [!WARNING]
> **💥 Caution: Weapon of Mass (UI) Destruction**
>
> This extension is made for fun and poses no real threat. However, it **breaks the usual look of websites** and can be addictive.
>
> - 💣 **The bomb drops exactly where you click** (thanks to Shadow DOM, even on strict sites like YouTube).
> - 🔊 **The explosion sound is synthesized on the fly** (no need to carry heavy mp3 files).
> - 🌐 **Language support**: EN / RU / CN.
> - 🛠 **Debug mode**: A checkbox in the menu enables detailed logs in F12.
>
> If the site still breaks (happens on very poorly coded pages) — just refresh the tab.

##  How to install (if you're not a dev)

1. Download the `.zip` archive from the **[Releases](https://github.com/elsan97/JDAM-extension/releases)** section (button above).
2. Unzip it to any folder on your PC (and don't delete it later, or the extension will break).
3. Open `chrome://extensions/` (or `edge://extensions/`) in your browser.
4. Enable the **Developer mode** toggle.
5. Click **"Load unpacked"** and select that folder.
6. Go to any website, click the 💣 icon, and choose your target.

##  How to build it yourself (for those who can read code)

If you want to pull it locally:
```bash
git clone https://github.com/elsan97/JDAM-extension.git
```
Then just drop the folder into `chrome://extensions/` and enjoy!
